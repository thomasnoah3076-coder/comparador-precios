# Glosario
Aqui se encuentran todos los terminos, metodos o librerias que se desconocen en el proyecto.

### Etapa 4: Analizador de ofertas

- ***Desempate:*** `specs/002_analidor_ofertas/tasks` En la subtarea 2.3 se encuentra el termino "desempate", esta palabra es usada en el proyecto para referirse al criterio o regla de negocio que va dicernir, determinar o elegir un resultado cuando este comparte puntos o carcteristicas con otro. En el caso particular de la subtarea 2.3 utilizamos el id de los productos para ordenarlos cuando estos comparten fechas.
- ***Hints:*** `specs/002_analidor_ofertas/tasks` En la subtarea 3.1, hace referencia al tipado de los parámetros de los metodos del archivo `analizador.py`.
- ***stdlibs:*** `specs/002_analidor_ofertas/tasks`En la subtarea 3.1,  (abreviatura de standard library, o biblioteca estándar) es el conjunto de módulos, paquetes y funciones integradas que vienen incluidos por defecto al instalar Python, sin necesidad de descargar o instalar paquetes externos.
- ***argparse:*** `specs/002_analidor_ofertas/tasks` En la subtarea 3.1, es el módulo estándar de Python para crear interfaces de línea de comandos (CLI), leer argumentos desde la terminal y generar mensajes de ayuda o error de forma automática
